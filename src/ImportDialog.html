Paste a CSV with a header line. Works with casparser output of your CAMS / KFintech CAS (pip install casparser → casparser CAS.pdf -p PASSWORD -o cas.csv, done on your own PC, so the password never leaves it), or any export with columns like date, scheme, amfi, folio, amount, units, nav, type. Tax rows (stamp duty, STT) and dividend payouts are ignored.
