👋 Welcome to MF Portfolio Tracker

This wizard sets up your sheet in about 5 minutes. You can run it again any time from the 📈 MF Tracker menu.

What the tracker does: one tab per fund with lot-wise purchases, FIFO redemptions, ELSS 3-year lock-in, STCG/LTCG split, daily NAV from AMFI, owner-wise dashboard and projection, weekly/monthly report mails, and a rule-based Advisor (allocation vs target, overlap, dip top-ups).

Privacy: your data stays in this Google Sheet in your own account. The script only calls mfapi.in for NAVs (no personal data is sent) and, if you enable it, reads your own Gmail for transaction mails.
